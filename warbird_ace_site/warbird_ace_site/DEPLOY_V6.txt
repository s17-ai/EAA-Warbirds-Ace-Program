DEPLOY V6 TO THE EXISTING GITHUB REPOSITORY

1. Unzip this package.
2. In GitHub, open the existing warbird_ace_site folder.
3. Upload the CONTENTS of this package's warbird_ace_site folder, replacing files with the same names.
4. Make sure static/forms/WoA_SAC_Application_Fillable_Template_Final.pdf appears in GitHub.
5. Commit the changes. Render should redeploy automatically.
6. After Render reports success, open /official-sac-form on the live site and confirm the revised PDF appears.
7. Open /application and hard-refresh the browser.

Render environment/email settings do not need to be re-entered for this code update.
