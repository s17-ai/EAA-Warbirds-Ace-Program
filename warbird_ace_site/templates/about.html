PROGRAM OVERVIEW

About the ACE Program

The ACE Program supports the evaluation process used for warbird pilots seeking a Statement of Aerobatic Competency.

What the site does

This site is designed around the existing operational workflow: a pilot locates an evaluator, makes arrangements for an observation, completes the evaluation, and the evaluator submits the completed application for EAA processing.

The electronic application does not replace the evaluation itself or the FAA issuance process. It replaces the handwritten, scanned application step.

Current workflow

  1. Locate an ACE.
  2. Coordinate the evaluation.
  3. Complete the flight observation.
  4. Fill and sign the digital SAC application.
  5. Submit the PDF directly to the EAA chairman.
  6. EAA processes the application and forwards it to the FAA.
DESIGN PRINCIPLE

Keep the official form familiar.

The interface is modern and responsive, but the generated document remains based on the existing three-page EAA-Warbird application. This minimizes procedural change for evaluators, EAA staff, and the FAA.
